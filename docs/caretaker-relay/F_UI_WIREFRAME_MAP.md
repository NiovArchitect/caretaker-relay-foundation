# F. UI Wireframe Map

Visual identity: calm, trustworthy, warm, accessible — **not** Otzar dark neon.  
Palette family: deep teal, soft seafoam, warm off-white, slate, sage, amber (attention), muted coral (safety).  
Motif: subtle flowing line (relay of information). Color never alone for state (icon + text + color).
